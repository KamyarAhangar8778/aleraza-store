# فروشگاه و مرجع تخصصی لوازم جانبی و قطعات لوازم خانگی آلِرضا (Aleraza)

پروژه فروشگاه آنلاین و لندینگ پیج تخصصی **لوازم جانبی، فیلترها و قطعات اورجینال لوازم خانگی آلِرضا** همراه با پیشخوان مدیریتی به سبک **وردپرس و ووکامرس (`/admin`)**، پایگاه داده ابری **Firebase Firestore** و سیستم کش دائمی تصاویر و فونت‌ها.

## امکانات کلیدی پروژه
- **ویترین لوازم جانبی تخفیف‌دار در ابتدای صفحه (Above-the-Fold)**: نمایش خودکار اقلام پرمصرف و تخفیف‌دار مانند فیلتر تصفیه آب سایدبای‌ساید، فیلتر هپا و پارویی توربو جاروبرقی، اکسسوری باریستا و اسپرسوساز، پایه‌های ضد لرزش لباسشویی و ظروف نسوز سرخ‌کن در بالاترین بخش صفحه اصلی.
- **پیشخوان مدیریت مستقل به سبک وردپرس (`/admin`)**:
  - مدیریت کامل لوازم جانبی، مشخصات فنی و سازگاری کالاها
  - قیمت‌گذاری بدون محدودیت رقم با پشتیبانی از کیبورد فارسی و انگلیسی و دکمه‌های تخفیف درصدی تک‌کلیکی
  - مدیریت کاروسل تصاویر هر کالا (تعیین تعداد عکس‌های قابل نمایش، آپلود، لینک و تغییر ترتیب)
  - مدیریت دسته‌بندی‌های لوازم جانبی
  - مدیریت کاربران (افزودن کاربر یا مدیر با نام، شماره موبایل و رمز عبور دلخواه)
- **سیستم کش دائمی تصاویر و فونت‌ها**: استفاده از هدرهای `Cache-Control: immutable`، سرویس‌ورکر (`sw-cache.js`) و `CacheStorage` مرورگر.
- **پشتیبانی خودکار از GitHub Pages**: دارای فایل `.github/workflows/deploy.yml` جهت بیلد استاتیک (`output: 'export'`) و انتشار خودکار روی GitHub Pages.

## انتشار روی GitHub Pages
1. پروژه را در ریپازیتوری GitHub خود Push کنید (یا از دکمه **Export to GitHub** در بالای محیط AI Studio استفاده نمایید).
2. در ریپازیتوری گیت‌هاب خود به تب **Settings -> Pages** بروید.
3. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** قرار دهید.
4. به محض قرار دادن روی GitHub Actions، ورک‌فلوی `Deploy Aleraza Store to GitHub Pages` اجرا شده و سایت شما روی آدرس GitHub Pages بالا می‌آید.
